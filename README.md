# School Student Management System

A full-stack School Student Management System for managing student records efficiently. The application provides CRUD operations, search, filtering, sorting, pagination, and student data export.

## 🚀 Features

- Add new students
- View all student records
- Edit student details
- Delete student records
- Search students by ID or name
- Filter students by class
- Sort student records
- Pagination
- Student count dashboard
- Form validation
- Gender selection
- Email and phone validation
- Export student data to PDF
- Export student data to Excel
- Export student data to Word
- REST API
- MongoDB database integration
- Responsive user interface
